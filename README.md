# ⚡ Diff Checker (EN)

A lightweight, portable text and code diff tool built with **.NET 10 Minimal API** and a custom **LCS (Longest Common Subsequence)** algorithm.

## Features
* **Synchronized Split View:** Side-by-side comparison with synchronized scrolling.
* **Intra-Line Highlighting:** Detects and highlights character-level differences within modified lines.
* **Unified Diff View:** Full-page sequential diff output with an overview minimap bar.
* **Viewport HUD:** Transparent, floating indicator showing current line ranges and scroll percentage.
* **Zero External Dependencies:** Built without third-party libraries, using native .NET 10 and a vanilla JS / Tailwind CSS frontend.

## Quick Start

```bash
dotnet run
```
The app will launch automatically in your default browser at http://localhost:5050.

# ⚡ Diff Checker (TR)

.NET 10 Minimal API ve özel LCS (Longest Common Subsequence) algoritması kullanılarak geliştirilmiş, hafif ve taşınabilir bir metin/kod karşılaştırma aracı.

## Özellikler
* **Senkronize Split Görünüm:** Kilitli kaydırma (scroll) desteğiyle yan yana karşılaştırma paneli.
* **Satır İçi (Intra-Line) Vurgulama:** Değişen satırlardaki karakter bazlı farkları tespit eden renklendirme.
* **Birleşik (Unified) Çıktı:** Sayfa altında tam ekran döküm ve sağ kenarda dikey görsel minimap rehberi.
* **Dinamik Navigasyon Kılavuzu (HUD):** Kaydırma esnasında satır aralığını ve dosya yüzdesini anlık gösteren saydam gösterge.
* **Sıfır Dış Bağımlılık:** Üçüncü parti paketler olmadan, doğrudan yerel .NET 10 ve saf JS / Tailwind CSS arayüzü.

## Nasıl Çalıştırılır?

```bash
dotnet run
```
Uygulama varsayılan tarayıcınızda otomatik olarak http://localhost:5050 adresinde açılır.
